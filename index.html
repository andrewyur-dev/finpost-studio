TIKTOK INTEGRATION

Authorization stays with TikTok.

FinPost Studio uses TikTok Login Kit for account authorization and the Content Posting API for creator-approved publishing. The creator logs in on TikTok, reviews the requested permissions, and can revoke access through TikTok.

The integration requests only the permissions required to identify the authorized creator and publish content they explicitly approve.

user.info.basicConfirm the authorized creator identity
video.publishPost a creator-confirmed video and caption
push_by_fileTransfer only the selected local MP4

DESIGNED FOR CONTROL

The creator remains the final decision-maker.

Account locks

The selected account profile is checked against the identity returned by the platform before upload.

Local token protection

OAuth tokens are encrypted on the creator’s device. FinPost never asks for a TikTok, Google, or Instagram password.

Disclosure checks

Creator-supplied sponsorship, affiliate, and educational disclaimers must remain in every platform’s copy.

No surprise publishing

Dry-run is the default. Live publishing requires an explicit final confirmation for every batch.
